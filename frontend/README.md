# IntelliFlow AI

**Smart Workflows. Seamless Automation.**

IntelliFlow AI is a workflow automation platform designed to help users create, manage, and automate workflows through a simple and intuitive interface.

## Features

- Create and manage workflows.
- Automate repetitive tasks.
- Monitor workflow execution.
- Manage workflow status and activities.
- Secure user authentication.

## Tech Stack

- **Frontend:** Next.js, React.js, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL, Prisma
- **Authentication:** Clerk
- **Other Tools:** Redis

## Getting Started

Clone the repository and install the dependencies.

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Project Structure

The project contains separate frontend and backend applications.

## Deployment

The application can be deployed using Vercel for the frontend and a suitable hosting platform for the backend.
